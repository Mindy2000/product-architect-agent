## 本轮检查原则

所有测试使用合成数据、固定模型响应或内存Dify传输。生成代码只在固定隔离容器运行。测试原始ZIP和独立恢复副本不含真实用户资料或Key；不修改原.env，不使用真实模型/视觉/Dify额度，不跑Windows完整链路，不发布Release。

`python -m unittest discover -s tests -v` 检查既有回归与本轮边界；`npm run typecheck`、`npm run build` 检查界面。先停止闲置工作台再执行 `python scripts/offline_quality.py`，它使用白名单源码临时副本；端口占用时拒绝运行。

主要新增测试为 `tests/test_closeout.py`，界面与交付的离线验证包含在发行源码的 `tests/integration/` 中。明确区分技术检查和需求验收；不人工替真实用户确认产品标准。

## 不在本轮内

真实自主成功率/供应商账单、Windows完整运行、正式发行、复杂文档结构或视觉验收准确率，均无新增验证结论。后续不继续自动生成更多阶段。
