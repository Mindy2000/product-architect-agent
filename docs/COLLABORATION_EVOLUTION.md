# 协作深化（0.6）

八项范围固定，不增加新平台功能。真实模型、视觉、Dify、Windows完整验证及正式发布继续暂缓。

| 项目 | 完成依据 |
|---|---|
|资料生命周期|查询、归档/还原、引用检查、带指纹的删除预览；被历史方案引用不可删除|
|意见闭环|采用→实施版本与证据→待确认→人工关闭，保留状态历史|
|规则范围|页面/功能/任务适用范围、任务选择、结构化冲突检查、冻结快照|
|视觉对照|桌面/手机、独立合成浏览器数据、冻结动画、遮罩/区域设置与证据绑定|
|离线评测|坏参数、过期证据、澄清、规则冲突、无进展修复；版本报告比较|
|自定义模板|源码/测试/通用规则选择与内容预览，私密检测，版本固定|
|源码关联|显式组件标记、行号、依赖关系与不确定性|
|执行回放|时间轴、来源快照/步骤/预算绑定，受限固定响应副本分支比较|

模板与回放不会执行导入脚本或调用供应商。像素变化、固定响应通过均不代表真实模型质量或人工验收。验证记录见末尾；未执行的范围不标为通过。

## 使用入口

- 项目详情 → **资料管理与意见闭环**：按关键词查找意见、基线和比较，查看归档，预览引用后确认删除。活动上限仍为40条意见、20份谱系基线、20份版本比较；归档总量最多活动上限的5倍。视觉PNG总量仍32 MiB。冻结方案、运行记录、其他比较及归档内容中的引用均阻止删除。
- 项目详情 → **协作与项目规则**：规则可限定整个项目、页面路径、功能标记或任务标记；范围按精确值匹配。修改需求区选择本次适用规则。默认只取项目通用规则。结构化同名字段值不一致会阻止方案冻结；相同正文提示重复，自由文本冲突不冒充已识别。
- 产品预览 → **视觉对照设置**：桌面1000×720/手机390×844。独立模式新建浏览器上下文，固定时钟/地区/动画设置，使用显式localStorage样本；全栈请求只读合成接口响应，未提供的返回404，不访问原业务库。矩形遮罩和局部比较区域与基线绑定，遮罩像素不计入变化比例。回到普通模式保留原浏览器数据。
- 项目详情 → **另存为可复用模板**：勾选/编辑受控源文件，保留三个入口和至少一份交互测试，选取通用规则，再预览全部内容并确认。疑似凭证、邮箱及私人路径阻止保存；不读取或复制附件、业务数据库、浏览器存储或环境配置。自动检测无法识别所有业务隐私，需要用户核对内容。模板最多60份不可变版本，可接续最新版本；旧方案固定原版本和摘要。
- 点选意见的**源码关联**显示文件行号。支持`data-pa-source="src/Component.tsx:行号"`显式标记并核对源码行；没有可靠标记时降级为文字候选。同时保存符号/导入索引及相关依赖，动态组件和重复文字明确标为不确定。
- 工作台设置 → **质量与成本评测**：三模板×两策略加五项故障注入，共11项。使用无凭证的临时源码副本；原工作台资源占用时拒绝启动。报告支持版本对照，只有相同套件与环境才提示可比较，新增/移除项单列。
- 项目详情 → **执行时间轴与固定决策分支**：查看输入、智能体响应、工具回执、源码差异、停止原因。选择当前源码或已提交修改前/后快照，绑定可匹配的LangGraph检查点、当前回执摘要和原资源限额。无检查点的历史任务明确显示未匹配，不伪造恢复依据。

## 意见闭环

待处理→已采用→已实施→待人工确认→已关闭，可退回或重新打开。用户确认包含意见的开发方案时，自动登记采用；后续状态记录理由、落实版本及源码指纹。实施版本必须属于原项目谱系且冻结了该意见。等待确认和关闭需要当前源码/运行环境/测试套件及页面检查一致的真实构建测试回执，关闭还需用户明确点击。历史关闭记录保留其当时依据，不自动成为后续版本的验收结论。

## 回放边界

每次比较两个固定决策分支，动作仅限`read_file`、`apply_changes`、`finish`、`stop`。副本使用受控路径、源码容量和SHA256前置条件；不复制密钥或业务数据、不执行生成源码、不启动网络/模型/命令。最多32步且不能超过原任务剩余步骤。结果保留分支步骤、停止原因、文件差异、原依据和零费用记录；临时文本副本退出后删除。

这是**源码操作与控制机制的固定回放**，不是完整业务运行时回滚，也不是重跑真实模型。数据库写入、浏览器动作及远程工具副作用仅作为原回执查看，不会重新执行。运行正确性仍由现有容器构建测试流程验证。

## 保存与兼容

新增资料沿用runs.sqlite3中的协作记录，截图仍在项目visuals目录，整套工作台备份自动包含。0.2–0.5可以按既有并排升级流程到0.6，不破坏旧任务协议、冻结资料或费用台账。没有新增依赖、供应商或默认付费调用。
