# Product Architect Agent：当前状态与有限收尾范围

更新：2026-11-07。版本：0.3.2。本文件是唯一的当前状态入口；其他阶段文档保留历史证据，不产生新的开发授权。

## 产品定义与完成边界

个人本地中文应用开发工作台。支持需求/方案确认→规划→受控代码工具→隔离构建→生成测试或固定独立套件→固定页面基础检查→最多三轮修复→交付/Trace/Git；逐条需求验收另行保存并绑定源码。运行状态 completed 仅表示执行完成。

生成范围固定为 React/TypeScript/Vite/Tailwind，最多12页、128受控文件、单份64 KiB、源码合计2 MiB。数据可用 localStorage 或已确认的固定 FastAPI/SQLite CRUD；不是任意后端、任意依赖或任意命令执行平台。

## 验收含义

- 构建通过：当前源码可以编译。
- 生成测试通过：Agent自己编写的测试通过，需求覆盖范围未知。
- 固定独立套件通过：选定的六类产品套件之一通过，不自动代表所有需求均被覆盖。
- 固定页面基础检查通过：已确认静态页面在桌面/手机宽度下挂载、未捕获错误、横向溢出、刷新和基本键盘焦点检查通过；参数页面仍需实际数据核对，不评价需求语义、美观或完整无障碍。
- 逐条确认：用户明确记录实际操作或独立套件与该条标准的对应关系。记录带当前源码/需求/运行环境摘要，Agent工具不能代写。
- 全部确认：当前技术检查通过且每条标准均有有效通过记录。证据内容与人工判断质量仍需审阅。

交付ZIP/报告是交付时快照；后续人工记录以项目面板的当前导出为准。

## 运行保护与容量

- 同一工作台一次只占用一个构建/浏览器/预览运行槽，降低默认2 GiB容器虚拟机过度并发的风险。互斥范围是同一工作台的正常运行；异常退出遗留容器仍须在运行管理中显式核对/清理，不代替虚拟机硬内存限制。预览占用资源时，其他运行清楚提示关闭或等待，不自动扩大内存。
- 工作台备份最多512 MiB、单文件128 MiB、30,000文件。知识库总量256 MiB，附件每应用256 MiB；累积可能超过整套备份上限，此时明确拒绝，不截断、不删除原数据。
- 维护并发1，最多4个待处理任务；重启标记中断，不自动重放。
- OCR并发1、进程组RSS采样保护768 MiB、单页30秒/整份300秒；不是硬内存隔离。
- Dify仅官方地址、用户确认免费策略后显式操作；累计保护线最高60，不自动降低观察用量或清空本地预留。解除暂停不重试请求，不清除不确定变更。
- 模型费用为本地保守估算，不能替代供应商账单；缺失用量时保留原预留，预算及既有消费记录继续保留。
