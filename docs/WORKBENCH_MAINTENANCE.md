# 工作台备份、脱敏诊断和首次使用向导

日期：2026-11-03。版本：0.2.0。入口：左侧「设置与维护」或右上角设置按钮。本轮不运行真实模型任务，不做Windows完整Docker验收，不调用Dify或千问。

## 已实现

### 整套工作台备份与恢复

先预览范围再下载ZIP，支持项目记录/方案/直接参考、本地SQLite检查点、工具执行记录、费用记录、Git历史、源码工作区、交付、本地知识库及原文、网页快照、视觉原图、业务数据库与附件、Dify本地绑定/缓存/额度策略及向导偏好。仅从已知工作台目录采集，测试实验目录不会混入。云端Dify知识库本体仍由平台托管，不联网导出。

排除.env和API密钥配置、虚拟环境/node_modules、Docker及OCR缓存、构建/测试缓存、日志/PID、临时上传、旧备份与恢复副本。非秘密设置只保留模型和预算等白名单，不迁移本机网络地址或容器context。资料正文原样备份，包中含私有业务内容，必须私下保管。若正文/历史记录中出现当前已配置的密钥，停止导出，不在未告知时改写或删减原资料。

备份要求开发与方案生成已停止、文档处理结束、交互预览关闭。HTTP维护门在快照前排空既有请求并拒绝新操作；SQLite使用backup API包含WAL中的已提交数据，生成逐文件SHA256/大小清单，前后核对文件变化。下载完成即移除服务端临时导出包，不自动上传。

恢复需上传→格式/应用版本/清单/哈希预览→明确勾选→确认。只支持相同应用版本，format=1。恢复目录固定在当前项目的<当前工作台目录名>-restored/<UUID>（与当前目录同级），来源和当前工作台保留，不接受任意目标目录。新目录包含当前受控软件源码和恢复资料；.env从空密钥模板生成，文字/视觉调用关闭，原费用台账保留。源码与业务数据保持容器所需权限；Git配置重建，拒绝hooks、外部alternates和链接。恢复不会安装依赖或执行生成代码，之后停止旧服务、在新目录运行安装/配置/启动入口。

相同上传token重复恢复返回已有副本，不覆盖新文件；失败清理本次暂存目录。限制：压缩与展开各512MiB、单文件128MiB、最多30,000项、最多10份上传预览；上传24小时有效，可在页面重新校验或移除暂存。拒绝越界、绝对路径、链接、大小写/Unicode归一化冲突、Windows保留名、重复/加密条目。

### 集中脱敏诊断

白名单收集系统/Python和六个关键依赖版本、工具是否存在、磁盘余量、配置布尔状态、任务状态与失败阶段计数。SQL只选择状态和阶段，不取出任务需求全文；不读取原始日志、源码、文档或业务数据库正文，不导出用户名/安装路径/Key。损坏运行JSON计数，数据库不可读时给固定状态而不泄漏错误文本。

先生成本地快照供预览，再下载同一份JSON和说明文件的ZIP。不会发给GitHub、模型或其他平台。预览10分钟有效，后续预览会移除过期的本功能临时JSON。下载ZIP完成后删除临时ZIP。包含范围和排除范围随诊断一起导出。

### 可视化首次使用向导

未启用模型的新浏览器首次打开时进入设置页；也可随时手动进入。展示Python/Git、Docker服务、前端固定镜像、文字密钥/预算/调用许可，以及可选后端/千问/Dify配置。可视化保存三个供应商各自Key，留空保留已有值，Key只在密码框输入并写入本机600权限.env；其他供应商配置保留。

只有文字模型的明确勾选会写入启用标志，累计预算限制0.25–99元，原费用不重置。千问/Dify这里只保存Key，不自动开启、上传或检索。配置写入采用原子替换，进程内开关不偷偷变更；页面对比已保存和已加载状态，提示停止/重启后重新检查。必要项与已加载配置一致后才能标记准备完成。不验证Key的远程有效性，也不运行模型请求。
